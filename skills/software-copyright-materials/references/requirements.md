# 软件著作权材料准备依据

核对日期 2026-10-22。依据为国家版权局公布的[《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)。提交前应再次核对中国版权保护中心的现行办事要求。

## 正式规则摘要

第九条列出申请表、鉴别材料和证明文件。第十条规定程序及一种文档通常各取前后连续30页，不足60页全交；除特定情况外，程序每页至少50行，文档至少30行。第十一条涉及身份及相应权属证明，第十七条要求A4。第二十一条列明材料不规范、名称署名不一致和权属争议等不予登记情形。

上述为概括说明。保密材料需另核对第十二条例外交存及第十三条封存安排，不能把自动筛选、随意删改或隐去内容当作已符合交存规则。

## 编辑建议和工具边界

- 宋体字号、页眉页脚样式、截图数量和占位图比例属于本工具的编辑建议，不应冒充全部法定要求。本工具不预设说明书至少15页，也不把图片高度自动折算为文档行数。
- 按实际软件范围确定完整源码及顺序，再确定交存页；核心文件初选或3000行统计均不能自动证明已形成合格的60页材料。完整保留原文、版权声明及版本证据。
- 名称、版本、著作权人、完成及发表事实须如实核实，未知保持待确认；按实际权属准备相应证明。工具使用权限不等于代签、提交或上传证件的授权。
- 使用真实运行截图；以Word母版替换图片，导出PDF后逐页检查。先确认最终内容与名称，再清理编辑提示，不能遗留占位图或未确认字段。
- 当前在线系统界面、费用及办理时限需另据官方信息核实。本工具不承诺登记成功、多个项目必定分别获证或任何费用结果。
