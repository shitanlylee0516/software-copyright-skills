# 软件操作手册编写与截图排版规范

本参考文档介绍软件用户操作手册的结构编排、排版标准以及推荐的工作流。

## 一、推荐的主工作流：Word 原生母版工作流

在准备软件著作权说明书时，最可靠的工作流遵循以下阶段：

```
[Markdown 结构草稿] + [元数据与截图槽位配置]
         │
         ▼ (通过 build_manual.py 脚本生成)
[排版规范的 Word 母版文档 (.docx)]
         │
         ▼ (人工在 Microsoft Word / WPS 中操作)
[右键单击占位图 -> 「更改图片」 -> 替换为真实运行全屏/主窗口截图]
         │
         ▼ (文字修订、样式校对、页眉版本号核对)
[导出为高质量 PDF 文档]
         │
         ▼ (人工逐页检查)
[终审确认并提交登记系统]
```

### 为什么在 Word 中使用「更改图片」？
- 脚本已为每个截图槽位设置了精确的标准比例与页面版心（横版 16:9 或竖版 9:16），并配置了段落防分页孤行规则（`keep_with_next`）。
- 直接在 Word 中右键点击占位图并选择**「更改图片」**（Change Picture），可以直接替换为真实截图文件。
- **注意**：替换真实截图时，必须保持原始宽高比，严禁拉伸变形实际截图。在 Word 中使用「更改图片」可能会保留原占位图的裁剪区域或缩放比例，因此替换后必须逐图检查是否有意外裁切（Crop）或比例失调，并适当调整使其完整适配版心。
- 避免直接按 Delete 删除占位图后再按常规插入图片，否则可能丢失版心约束并导致图注与截图跨页分离。

## 二、页面与版式规范（技术排版建议）

1. **纸张与边距**：标准 A4 页面（21.0cm × 29.7cm），上、下、左、右页边距统一为 2.2 cm。
2. **字体与字号**：
   - 大标题：宋体 / SimSun 18～20 pt 居中，黑体加粗。
   - 二级标题：宋体 / SimSun 14～15 pt 左对齐加粗。
   - 三级标题：宋体 / SimSun 12 pt 左对齐加粗。
   - 正文：宋体 / SimSun 五号（10.5 pt），常规黑色，行距 1.25 倍。
   - 代码片段：Consolas 或 Courier New 9.5 pt。
3. **表格规范**：
   - 居中对齐，浅灰色（`#D9D9D9`）细实线边框，内边距约 100 twips。
   - 表头行浅灰背景（`#F5F5F5`）填充，开启跨页重复表头。
   - 禁止固定行高，确保单元格内文字自适应完整呈现。
4. **页眉与页脚**：
   - 页眉：
     - 左上角（左对齐）：显示「软件全称 版本号」，字号 9 pt 黑色。
     - 右上角（右对齐）：显示动态页码「第 X 页 共 Y 页」（使用 Word `PAGE` 与 `NUMPAGES` 自适应域），字号 9 pt 黑色。
     - 边框线：页眉下方添加 0.75 pt 单细横线。
   - 页脚：根据最新软著申报排版规范，页码统一置于页眉右上角，页脚保持空白。封面页不显示页眉与页码。

## 三、排版与渲染限制说明

- **无渲染引擎环境限制**：自动化测试与脚本主要验证 OpenXML 的 XML 结构、样式名、域代码与占位图属性是否合规。在缺少 Microsoft Office 渲染引擎的环境中，未执行视觉渲染，并不代表已完成最终排版验收。生成的 `.docx` 母版必须由人工在专业办公软件中完成真实截图替换和**逐页检查**。
- **直接 PDF 仅为可选辅助**：Markdown 直接转 PDF 仅为可选辅助方案；直接生成的独立 PDF 无法作为 Word 排版渲染效果的等价证明。
